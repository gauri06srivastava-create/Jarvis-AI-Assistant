# 🤖 Jarvis AI Assistant

An AI-powered voice assistant built using Python that interacts with users through voice commands and provides intelligent responses.

## 🚀 Features

- 🎙️ **Voice Recognition:** Recognizes user voice commands.
- 🔊 **Text-to-Speech:** Converts responses into spoken words.
- 🧠 **AI Integration:** Generates intelligent responses using Groq API.
- 🌐 **Web Automation:** Opens websites through voice commands.
- 💾 **Memory Support:** Uses JSON-based local memory.
- ⚡ **Desktop Assistance:** Performs basic desktop operations.

## 🛠️ Tech Stack

- Python
- SpeechRecognition
- pyttsx3
- Groq API
- SoundDevice
- Webbrowser
- Python-dotenv
- JSON

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/gauri06srivastava-create/Jarvis-AI-Assistant.git
```

**2. Navigate to the project**

```bash
cd Jarvis-AI-Assistant
```

**3. Create a virtual environment**

```bash
python -m venv venv
```

**4. Activate the environment (Windows)**

```bash
venv\Scripts\activate
```

**5. Install dependencies**

```bash
pip install -r requirements.txt
```

**6. Configure API Key**

Create a `.env` file and add your Groq API key:

```env
GROQ_API_KEY=your_api_key_here
```

**7. Run Jarvis**

```bash
python main.py
```
